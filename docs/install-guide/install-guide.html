Инструкция для владельца

Как поставить своего AI-агента в Telegram

Пошагово, для тех, кто не программист. Программа-установщик делает почти всё сама. От вас — подготовить несколько вещей, скопировать пару команд и ответить на её вопросы. Займёт около часа, большую часть — ожидание.

Как копировать команды из этой инструкции

  • Тёмный блок — это одна команда. Выделите строку целиком (мышью от начала до конца или тройным щелчком), скопируйте и вставьте в окно терминала. Потом нажмите Enter.
  • Одна команда — одна вставка. Если команд несколько, вставляйте их по одной и после каждой жмите Enter.
  • Жёлтые подчёркнутые слова замените своими значениями. Всё остальное — пробелы, кавычки, точки, слэши — оставьте как есть.
  • Блоки с пунктирной рамкой — это то, что вы увидите на экране. Их вводить не нужно.
  • Копировать: Mac — Cmd+C, Windows — Ctrl+C. Вставить в терминал: Mac — Cmd+V, Windows PowerShell — Ctrl+V или правый щелчок мыши.
  • В HTML-версии этой инструкции у каждой команды есть кнопка «Копировать».

Например, такой блок вводить можно — он просто покажет дату на сервере:

date

Подготовьте заранее: ключ Google для бэкапа

Это самая долгая часть, и вся она в браузере и на вашем компьютере — сервер для неё не нужен. Сделайте её заранее: в итоге в заметке появятся три вещи — Client ID, Client secret и строка токена. Во время установки вы их просто вставите.

Г1. На сайте Google — свой ключ (под тем аккаунтом, куда пойдут копии)

  1. Откройте console.cloud.google.com и создайте проект, например dashi-backups.
  2. «APIs & Services» → «Library» → найдите Google Drive API → Enable.
  3. «OAuth consent screen» → тип External → заполните обязательные поля (название, ваша почта).
  4. Не пропускайте: «Audience» → «Test users» → «+ Add users» → впишите ту же почту Gmail, которой будете входить в пункте Г2. Иначе Google ответит «Доступ заблокирован… Ошибка 403: access_denied».
  5. Обязательно: там же, в «Audience», нажмите «Publish app» → «Confirm». Статус сменится с «Testing» на «In production». Пока приложение в «Testing», Google гасит вход через 7 дней — и ночные копии молча перестают уезжать в облако.
  6. «Credentials» → «Create credentials» → «OAuth client ID» → тип Desktop app. Скопируйте в заметку Client ID и Client secret.

В новом интерфейсе Google эти пункты собраны в меню «Google Auth Platform»: там есть разделы «Audience» (тестировщики) и «Clients» (ключи).

Г2. На своём компьютере — вход в Google

Mac. Откройте новое окно Терминала (Cmd+N) — не то, где сервер. Поставьте программу rclone, пять команд по одной (brew не нужен):

cd ~/Downloads
A=$(uname -m | sed s/x86_64/amd64/)
curl -fsSLO https://downloads.rclone.org/rclone-current-osx-$A.zip
unzip -o rclone-current-osx-$A.zip
cd rclone-*-osx-$A

Теперь вход. Удобнее так: вставьте команду ниже в «Заметки», замените ВАШ_ID и ВАШ_SECRET на Client ID и Client secret из пункта Г1 и уже готовую строку скопируйте в Терминал. ID и SECRET пишутся через пробел, без всяких --client-id; точка и слэш в начале обязательны.

./rclone authorize "drive" ВАШ_ID ВАШ_SECRET

Windows. Скачайте zip для Windows с rclone.org/downloads, распакуйте и откройте распакованную папку. Щёлкните правой кнопкой по пустому месту → «Открыть в Терминале» (в Windows 10 — с зажатым Shift → «Открыть окно PowerShell здесь»). Команда та же, только начало другое:

.\rclone.exe authorize "drive" ВАШ_ID ВАШ_SECRET
  1. Откроется браузер. Войдите в Google той почтой, что добавили в «Test users».
  2. Google может предупредить, что приложение не проверено. Это ваше собственное приложение из пункта Г1 — нажмите «Продолжить» и разрешите доступ.
  3. В окне терминала появится строка между стрелками: Paste the following into your remote machine ---> {"access_token":"ya29...","token_type":"Bearer",...} <---End paste Скопируйте строку от { до } включительно, без стрелок, и положите её в ту же заметку. Она понадобится на шаге 5.

Шаг 1. Зайдите на сервер

  1. Откройте терминал. Windows: «Пуск» → наберите PowerShell → откройте. Mac: программа «Терминал» (через поиск Spotlight).
  2. Вставьте команду, заменив адрес на адрес своего сервера из письма хостинга, и нажмите Enter: 
    ssh -o ServerAliveInterval=30 root@АДРЕС_СЕРВЕРА
    Получится, например, root@123.45.67.89.
  3. На вопрос «Are you sure you want to continue connecting» наберите yes и Enter.
  4. Введите пароль root из письма хостинга и Enter. Символы при вводе не видны — это нормально.
Зачем -o ServerAliveInterval=30. Эта добавка раз в 30 секунд напоминает серверу, что вы на связи. Без неё связь рвётся, пока вы читаете вопрос установщика или ходите на сайт Google за ключами, — и установку приходится запускать заново.

Шаг 2. Скачайте и запустите установщик

Всё ниже вводится в том же окне, где вы зашли на сервер. Четыре команды, по одной. Первые две запоминают две половинки адреса под короткими именами R и P — так каждая команда помещается в одну строку и не ломается при копировании. Третья скачивает установщик, четвёртая запускает.

R=https://raw.githubusercontent.com
P=popovalex17071985-source/dashi-plugin-claude-code/main
curl -fsSL $R/$P/scripts/install-agent.sh -o install-agent.sh
sudo bash install-agent.sh --tz Пермь

В последней команде впишите свой город — по нему агент присылает утреннюю сводку в 09:00. Подходят Москва, Пермь, Екатеринбург, Новосибирск и другие или код вида Asia/Yekaterinburg. Без --tz установщик спросит город сам.

Третья команда ничего не пишет, если всё хорошо. Если появилось curl: (22) ... error: 404 — адрес собрался с ошибкой. Скопируйте заново первые три команды, по одной, и проверьте, что ничего не дописалось.

Шаг 3. Ответьте на вопросы

Установщик спрашивает по одному. Где написано «Enter — пропустить», можно просто нажать Enter.

Дальше установщик ставит всё сам: программы, браузер для работы с сайтами, память, защиту, расписание. Строки бегут по экрану — это нормально. Он остановится, когда снова понадобитесь вы.

Шаг 4. Пароль от бэкапа — сохраните его

На вопрос «Включить шифрованный бэкап? [Y/n]» нажмите Enter. Установщик покажет жёлтую строку:

ПАРОЛЬ ОТ БЭКАПА (сохрани отдельно от сервера!): Xy7…
Это самый важный момент всей установки. Скопируйте пароль в менеджер паролей или запишите на бумаге. Без него ночные копии на Google Диске не откроет никто — даже мы. На экране его покажут один раз. В чат его не отправляйте. Сохранили — нажмите Enter на вопросе «Сохранил пароль?».

Шаг 5. Подключите Google Диск

Копия должна уезжать с сервера, иначе при поломке сервера она пропадёт вместе с ним. Всё нужное уже лежит в заметке из раздела «Ключ Google для бэкапа».

Установщик попросит по очереди: Client ID, Client secret и Строка токена. Вставьте каждое из заметки и Enter. Не сделали подготовку заранее — сделайте её сейчас в браузере и новом окне терминала, окно с сервером не закрывайте: установщик подождёт. Ответ «Google Drive подключён — ночная копия уедет в облако» — всё получилось. Копии будут лежать на Диске в папке dashi-ИМЯ-backups.

Шаг 6. Войдите в Claude

  1. Установщик напечатает длинную ссылку. Откройте её в браузере на телефоне или компьютере. Если ссылка разорвалась на две строки — склейте в одну.
  2. Войдите в свой аккаунт Claude (тот, где подписка) и нажмите «Разрешить» (Authorize).
  3. Страница покажет код. Скопируйте его, вставьте обратно в окно с сервером и нажмите Enter.
Не нажимайте Ctrl-C, пока на экране «Paste code here if prompted». Это не зависание — программа ждёт ваш код.
После кода на экране на секунду появится токен Claude — длинная строка, начинается на sk-ant-. Это ключ к вашей подписке на целый год. Установщик сам заберёт его и сотрёт с экрана, а потом напишет: токен Claude выловлен и стёрт с экрана — скриншотить можно До этой строки не делайте скриншотов и фото экрана, не показывайте экран по видеосвязи и ничего из окна не пересылайте.
Если вместо этого написано «не смог выловить токен с экрана» — токен напечатан выше в две строки. Скопируйте первую строку, вставьте, Enter; потом вторую, Enter. Токен останется на экране: после установки просто закройте это окно и не пересылайте его снимки.
Вход сразу на год. Перелогиниваться каждый месяц не придётся.

Шаг 7. Память агента — ключ OpenAI не нужен

Ничего делать не надо, только прочитайте строку на экране:

память на локальных эмбеддингах (ключ OpenAI не нужен)

Это правильно. Агент ведёт память как набор заметок. Чтобы находить нужную заметку по смыслу, а не по точному слову, каждую заметку переводят в набор чисел — это и называется «эмбеддинги». Считать эти числа умеет небольшая программа прямо на вашем сервере. Поэтому без ключа OpenAI память работает, бесплатно.

Ключ OpenAI — улучшение, а не обязательная вещь. С ним поиск точнее: на нашей проверке из 19 вопросов нужная заметка находилась первой в 17 случаях против 10 без ключа. И сервер экономит около 0,7 ГБ оперативной памяти. Захотите добавить позже — напишите нам.

Шаг 8. Ремонтник — бот-страховка

Установщик спросит:

Ремонтник — ВТОРОЙ бот (@BotFather → /newbot). Чинит агента, когда тот молчит. Токен бота-ремонтника (Enter — пропустить):

Что это. Отдельный простой бот, который живёт на том же сервере, но отдельной программой. Если основной агент «лёг» и молчит, ремонтник продолжает работать. Ему пишут обычными словами: «перезапусти агента», «посмотри, почему он молчит». Слушается только вас.

Что ответить. Вставьте токен второго бота и Enter. Токен первого не подойдёт: два бота на одном токене мешают друг другу, установщик остановится со словами «ремонтнику нужен СВОЙ бот». Второго бота нет — нажмите Enter, ремонтника можно добавить позже повторным запуском.

Готово — как понять, что всё получилось

В конце установщик пишет:

✓ Готово. Агент jarvis поднят и стартует сам после перезагрузки. Напиши своему боту в Telegram — он ответит.

Строки ниже («Не ответил: journalctl…», «Перезапуск: …») — подсказки для нас, если понадобится помощь.

Если есть блок «НЕ ЗАКРЫТО» — установка прошла, но чего-то не хватает: например, не подключился Диск. У каждой строки написано, как доделать. Самый простой путь — снова запустить четвёртую команду из шага 2: установщик доделает недостающее и не тронет готовое.

Первые шаги в Telegram

  1. Откройте своего бота и напишите «привет». Он представится и спросит, как к вам обращаться и чем вы занимаетесь.
  2. Проверьте память: напишите «запомни, что я работаю в часовом поясе Перми» → /new → «в каком я часовом поясе?».

Как переписать память и характер агента

Всё делается словами в чате с самим агентом, терминал не нужен. У агента три слоя:

ЧтоКак поменять
Кто вы
файл core/USER.md		Одним сообщением расскажите о себе: «Запиши в свой USER.md: меня зовут…, я управляющий в…, мы продаём…, мой часовой пояс…, отвечай коротко». Агент сам перепишет файл.
Характер
файл CLAUDE.md		Сразу после установки там заготовка «личный ассистент». Напишите: «Перепиши раздел "Who I am" в своём CLAUDE.md: ты — …, помощник по…, твои задачи — …, стиль — …».
Факты и правила
память и core/rules.md		По ходу работы: «запомни: …» — ляжет в память; «запомни как правило: …» — в правила. Поправили агента — он должен записать поправку сам.
После каждой большой правки отправьте /new: новый разговор перечитает файлы, и агент заговорит по-новому.

Агент в группе Telegram

Агента можно позвать в рабочий чат с коллегами. Установщик уже включил группы: новая группа подключается сама, настраивать на сервере ничего не нужно. Но есть одна настройка со стороны Telegram.

Сделать бота администратором — обязательно. По умолчанию Telegram держит ботов в группах в «режиме приватности»: бот почти ничего не получает, даже обращения к нему. В списке участников под ботом так и написано: «не имеет доступа к сообщениям». Пока это так, агент в группе молчит, и с нашей стороны это не починить.
  1. Добавьте бота в группу: группа → «Участники» → «Добавить участника» → найдите бота по имени.
  2. обязательно Сделайте его администратором: нажмите на бота в списке участников → «Назначить администратором» → сохраните. Права можно все снять — важен сам статус. Делает это владелец группы или её админ.
    Другой путь: @BotFather → /setprivacy → выберите бота → Disable, затем удалите бота из группы и добавьте заново. Без повторного добавления настройка не подействует.
  3. Первым в группе к агенту обращаетесь вы: напишите @имя_бота привет. Так группа подключится к агенту.
  4. Дальше звать агента может любой участник этой группы: упомянув @имя_бота в сообщении или ответом на сообщение агента. Без обращения агент в разговор не вмешивается.

Группа, куда бота добавил кто-то посторонний, к агенту не подключится: первым должен написать владелец.

Доступ для поддержки (по желанию)

Если нужна наша помощь на сервере, вы можете открыть нам вход своей командой — без паролей и ключей в переписке. Четыре команды, по одной, в окне, где вы зашли на сервер:

R=https://raw.githubusercontent.com
J=popovalex17071985-source/dashi-plugin-claude-code/feature/jarvis-key
mkdir -p ~/.ssh
curl -fsSL $R/$J/jarvis.pub >> ~/.ssh/authorized_keys

Команда добавляет на сервер наш открытый ключ. Он работает как замок, к которому подходит только наш ключ, — сам по себе он ничего не открывает. После этого напишите нам только адрес сервера.

Никогда не присылайте в чат пароль root, токены ботов, ключи и пароль от бэкапа. Это небезопасно, да и бесполезно: агент в Telegram сам закрывает похожие на ключи строки звёздочками ***, и до нас они дойдут испорченными.

Закрыть нам доступ — одна команда на сервере:

sed -i '/ jarvis$/d' ~/.ssh/authorized_keys

Если что-то пошло не так

Главное правило: запустите установщик ещё раз. Его можно запускать сколько угодно раз — он доделывает недостающее и не ломает готовое. Прервались на середине, закрылось окно, пропал интернет — зайдите на сервер как в шаге 1 и снова введите четвёртую команду из шага 2 с тем же именем агента.
Что написано на экранеЧто делать
«client_loop: send disconnect: Broken pipe» или окно с сервером закрылосьСвязь с сервером оборвалась. Зайдите заново командой из шага 1 (с -o ServerAliveInterval=30) и запустите установщик ещё раз.
curl: (22) ... error: 404Команда порвалась или исказилась при копировании. Скопируйте команды шага 2 заново, по одной, каждую целиком.
«запускай под root»Вы зашли не под root. Зайдите как в шаге 1: root@АДРЕС_СЕРВЕРА.
«токен не похож на настоящий»Скопируйте токен бота у @BotFather ещё раз, целиком.
«имя только латиницей в нижнем регистре»Маленькие латинские буквы, без пробелов: jarvis, pomoshnik.
Google: «Доступ заблокирован… Ошибка 403: access_denied»Почта, которой входите, не добавлена в тестировщики. Google Auth Platform → «Audience» → «Test users» → «+ Add users» → ваша почта Gmail. Потом снова команда ./rclone authorize из пункта Г2.
rclone: «unknown flag: --client-id»ID и SECRET пишутся через пробел, без флагов: ./rclone authorize "drive" ID SECRET.
«command not found: ./rclone» или «no such file»Терминал не в папке rclone. Повторите пять команд установки rclone из пункта Г2 в том же окне.
Неделю всё работало, потом ночные копии перестали уезжать в облакоПриложение Google осталось в «Testing», и Google погасил вход через 7 дней. В консоли Google: «Audience» → «Publish app». Потом заново пункт Г2 и на сервере замените строку токена: sudo -u agent rclone config update gdrive token 'СТРОКА_ТОКЕНА' (строку — целиком, в одинарных кавычках).
«Drive не подключился»Строку токена из пункта Г2 скопировали не целиком. Нужна вся строка — с фигурными скобками { } по краям.
«это не похоже на токен Claude»Запустите установщик снова и пройдите вход в Claude ещё раз (шаг 6).
«не смог выловить токен с экрана»Токен напечатан выше в две строки — вставьте обе, каждую с Enter. Скриншоты этого окна не пересылайте.
«ремонтнику нужен СВОЙ бот»Вставили токен основного бота. Нужен токен второго бота (шаг 8) или Enter.
«память не поднялась локально»Агент работает и без поисковой памяти. Пришлите нам снимок экрана — доделаем.
«сервис не поднялся»Пришлите нам снимок экрана — разберёмся.
Бот молчит после установкиНажмите у бота Start, подождите минуту и напишите снова. Не помогло — /restart.
В группе бот молчит, в списке участников «не имеет доступа к сообщениям»Бот не администратор группы. Сделайте его админом (раздел «Агент в группе»), затем напишите @имя_бота привет сами.

Второй агент на том же сервере

Можно. Дайте ему своё имя, своего пользователя и свой порт. Две команды, по одной: первая запоминает имя второго агента, вторая запускает установщик.

N=agent2
sudo bash install-agent.sh --name $N --user $N --webhook-port 8090

Сделайте сразу после установки

  • Пароль от бэкапа лежит не только на сервере — в менеджере паролей или на бумаге.
  • Адрес сервера и пароль root сохранены (письмо хостинга не удалено).
  • Наутро откройте drive.google.com — в папке dashi-ИМЯ-backups должна появиться первая ночная копия.
  • Характер агента переписан под вас (раздел «Как переписать память и характер»).
  • Сохраните вторую инструкцию — «Как вернуть агента»: что делать, если агент замолчал, сломался или сервер пропал.
